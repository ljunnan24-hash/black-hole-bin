# Support / 获取帮助

Black Hole Bin is maintained as an open-source project. Community support is
best-effort; there is no guaranteed response time.

黑洞垃圾箱是开源项目，维护与答疑均为尽力而为，不承诺固定响应时间。为避免问题
遗漏，请按下面的入口反馈。

## Questions, ideas and usage help / 使用问题与想法

Use [GitHub Discussions](https://github.com/ljunnan24-hash/black-hole-bin/discussions)
for installation questions, ideas, screenshots and general usage help.

安装咨询、功能想法、使用截图和一般讨论，请发到 GitHub Discussions。

## Reproducible bugs / 可复现问题

Use the repository's
[structured issue forms](https://github.com/ljunnan24-hash/black-hole-bin/issues/new/choose).
Test drag/drop behavior with a disposable local file. Remove private filenames,
paths and account details from screenshots or logs before posting.

可复现错误请使用结构化 Issue 表单。首次复现时只使用无用的本地测试文件；提交
截图或日志前，请删除私人文件名、路径和账户信息。

Windows users who can test a real device are especially welcome to follow the
[Windows hardware smoke-test guide](docs/WINDOWS_TESTING.md).

## Security and file-safety problems / 安全与文件风险

Do not open a public issue for unexpected permanent deletion, arbitrary file
movement, path-validation bypasses or code execution. Report these through
[GitHub private vulnerability reporting](https://github.com/ljunnan24-hash/black-hole-bin/security/advisories/new).
See [SECURITY.md](SECURITY.md) for the project's safety invariants.

永久删除、非预期文件移动、路径校验绕过或代码执行问题不得公开披露，请使用上述
私密漏洞报告入口。

## Current distribution limits / 当前发布限制

- Windows installers are a public unsigned preview and may show a SmartScreen
  reputation warning.
- Windows recovery currently uses the Recycle Bin's standard **Restore** action.
- macOS currently requires a source build; a signed and notarized download is
  not available yet.
- Do not weaken system-wide security settings to run this project.
